# mydraw — notes for agents

Roadmap and phase status: `plan.md`. Read it before starting a phase.

## Architecture
- `app/src/main.ts`: Electron main. Serves `web/dist` over the privileged `app://mydraw` scheme (prod) or loads `MYDRAW_DEV_URL` (dev). All file I/O, dialogs, menus, settings and the crash-recovery folder live here. The renderer may only write to paths the user opened or picked (`allowedPaths`).
- `app/src/cli.ts`: the headless `mydraw` CLI main process (see Export part 2). `app/src/pdf.ts`: PDF printing for both.
- `app/src/preload.ts`: exposes `window.mydraw` (typed by `MydrawBridge` in `shared/types.ts`). Context isolation + sandbox on; add new IPC here and in `shared/types.ts` together.
- `web/src/App.tsx`: tabs, save/autosave, recovery, file-watch conflicts, close flow. One mounted `<Excalidraw>` per tab (hidden when inactive) so each keeps its own undo history. Latest state is read through refs (`tabsRef`, `settingsRef`, `apis`) because callbacks come from Excalidraw, IPC and timers.
- Dirty tracking: `sceneHash` (element versions + count + background) compared with a per-tab baseline set on first `onChange` after load, after save, and after reload.
- Drawing style (Clean/Sketch) sets `currentItem*` app state only; it never edits existing elements.

## Stencil library
- `app/src/library.ts` (`LibraryStore`): scans the library folder (collections = top-level folders; items = .svg/.png, `.stencil.json`, entries of `.excalidrawlib`), watches it, keeps favorites/recent in `library.json`. Item ids are root-relative paths (`#n` for .excalidrawlib entries). Files are served to the renderer via the `mdlib://library/<path>` protocol, confined to the root.
- `app/src/packs.ts`: icon-pack downloader (plain Node; also `scripts/fetch-packs.mjs`). Packs build in `.<Collection>.installing` and replace only folders whose `collection.json` has `managedBy: "mydraw-packs"`.
- `web/src/library/stencilContent.ts`: item → elements (+ image files, fileId = SHA-1 of the bytes), `cloneForInsert` (fresh ids, remapped bindings/groups), `insertStencil`. Reuse these for MCP `place_stencil` in Phase 2.
- Excalidraw's own Library panel: `initialData.libraryItems` + `onLibraryChange` → `Library/Excalidraw Library/library.excalidrawlib`, synced to all tabs via `updateLibrary` (hash check prevents loops).
- Panel → canvas drag uses the `application/x-mydraw-stencil` type and is handled in a capture-phase drop listener in `App.tsx`, before Excalidraw sees it.
- Icon recolor: `shared/recolor.ts` (`recolorSvg`, pure + unit-tested) rewrites fills/strokes/stops/currentColor, keeping near-white and transparent parts. `web/src/library/iconColor.ts` swaps the element's `fileId` to the recolored SVG and keeps the original SVG in `customData.mydrawOriginalSvg` (+ `mydrawIconColor`), so recolors never compound and "Original" restores. Reuse for an MCP `recolor` tool.
- Excalidraw 0.18 records selection changes in undo history.
- Dark mode: Excalidraw inverts the canvas with a CSS filter and pre-corrects raster images, but not files whose mimeType is exactly `image/svg+xml`. SVG icon files use `image/svg+xml;mydraw=truecolor` (`web/src/library/trueColor.ts`, applied on insert, recolor and file open) so icons keep their real colors in both themes and in dark exports. Detect SVGs by data URL, not mimeType.
- SVG files must have numeric width/height (`ensureSvgSize`), otherwise Excalidraw's raster-image export crops them.
- Eyedropper (`web/src/library/pickColor.ts`): `elementAt` hit-tests scene coords (topmost; bound text → container; unfilled shapes only near their outline; lines/arrows last) and `colorOfElement` reads the real color (`customData.mydrawIconColor`, `dominantSvgColor`, raster quantisation, or fill/stroke). Pick mode swallows the canvas click in a capture-phase listener so the selection is kept.
- Icon color lives in the Colors tab of `StyleSection` as the **Icon** target (shown when SVG icons are selected; the only target when only icons are selected). It reuses the palette, shades, last-custom swatch, eyedropper and `ColorPicker` (live preview via `onIconColor(color, true)`), plus an **Original colors** chip. There is no separate icon color section any more.
- Live recolor previews use `CaptureUpdateAction.NEVER`; `IconRecolorSession` restores the pre-drag elements (NEVER) before the final IMMEDIATELY change, so a drag is one undo step. Don't use EVENTUALLY here: in 0.18 it merges into the *previous* committed change.
- When swapping an image's `fileId`, call `updateScene` first and `addFiles` after; Excalidraw only starts loading images for files added while an element references them (otherwise a grey placeholder shows until some later update).
- Excalidraw handles keyboard shortcuts only when its canvas has focus (tests click the canvas first).
- Console "font-src" CSP errors for `esm.sh` are expected: Excalidraw lists a CDN fallback after our local fonts; CSP blocks it so the app stays offline.

## Agent control (MCP, Phase 2)
- Path: Claude Code → `mcp/src/index.ts` (stdio MCP server, bundled to `mcp/dist/index.js` by `scripts/build-mcp.mjs`) → HTTP `POST 127.0.0.1:<port>/rpc` → `app/src/control.ts` → `app/src/agent.ts` (main) → IPC `agent:command` → `web/src/agent/executor.ts` (renderer) → reply on `agent:reply`.
- `control.ts`: loopback only, random port, 32-byte key as `Authorization: Bearer`. Refuses any request with an `Origin` header or a non-loopback `Host` (CSRF / DNS rebinding). `{port, key, pid}` in `<userData>/control.json`, chmod 600, removed on quit.
- `agent.ts` runs library and file-system methods in main (`search_stencils`, `add_stencil_file`, `delete_stencil`, `open_drawing`, writing exports, allowing `save` paths) and forwards the rest. `place_stencil` gets the full `LibraryItem` from main, so freshly added stencils work before the renderer's index refreshes.
- Executor: commands run strictly one at a time against the latest scene; every scene change is a single `updateScene(IMMEDIATELY)` that merges by element id, so one MCP call = one undo step and user edits made meanwhile are kept. Selection changes from `select` use `NEVER`.
- `web/src/agent/sceneOps.ts`: `buildElements` (skeletons via `convertToExcalidrawElements` with `regenerateIds: false`; arrows with `from`/`to` are drawn edge to edge with `shared/geometry.ts` and bound by hand, because the converter only binds within its own batch), `applyUpdates` (moves/resizes re-centre labels via `relabel` and `reroute` bound arrows), `deleteElements` (unbinds arrows), `describe` (compact `get_scene` output; bound labels folded into their container).
- Undo/redo click the tab's own `[data-testid="button-undo"]` (each `DrawingView` root has `data-md-tab`); Excalidraw's API has no undo call.
- Drawings are addressed by `drawing` = tab id, file path or title; default active tab.
- MCP finds the app via `MYDRAW_USER_DATA` (default `~/Library/Application Support/mydraw`). If it isn't running it launches `/Applications/mydraw.app` (or `MYDRAW_APP`), else the dev build with the branded Electron (`npm run build` first). `MYDRAW_NO_LAUNCH=1` disables launching (smoke test).
- Register: `claude mcp add --scope user mydraw -- node ~/Projects/mydraw/mcp/dist/index.js`.

## Diagram generation (Phase 5)
- `shared/diagram.ts`: `DiagramSpec` (nodes, edges, zones, direction, algorithm, routing, legend), `normalizeSpec` (validates agent input, fills edge ids), zone palette/tints, `uniquifySpec` (renames ids that clash with the drawing; used for Mermaid and templates).
- `shared/layout.ts`: ELK via `elkjs/lib/elk.bundled.js` (no worker). Zones are compound nodes (`INCLUDE_CHILDREN`), coordinates absolute (`elk.json.shapeCoords/edgeCoords: ROOT`). ELK can ignore a compound's minimum size with cross-hierarchy edges, so zones are widened afterwards.
- `shared/routing.ts`: `elbowRoute` (simple orthogonal router used by `connect`/reroute), `tidyRoute` + `inset` (clean ELK routes: drop collinear points, give end runs room, stop 5px short), `curvedPoints`, `fixedPointFor`.
- `shared/mermaid.ts`: own flowchart parser -> DiagramSpec (same layout/zones as build_diagram). Non-flowchart Mermaid goes through `@excalidraw/mermaid-to-excalidraw` (dynamic import, renderer).
- `shared/templates.ts`: starter specs. Icons are names or `Collection:query` (`findStencil` in `shared/library.ts`); missing packs fall back to shapes with a warning.
- `web/src/agent/diagram.ts`: `makeIconNode`, `makeZone`, `buildDiagram`, `buildLegend`, `autoLayout`. Main (`app/src/agent.ts`) validates specs and resolves icons, the renderer builds and commits (one undo step).
- **Icon node** = borderless container rectangle (caption = bound text, `verticalAlign: bottom`) + image, grouped; `customData.mydrawNode = "icon"`, `mydrawStencil`. Arrows bind to the container so they never cross the caption; `bindTarget` redirects an image/caption id to its node. `recolor`/`get_color` on a node act on its image. `get_scene` shows it as `type: "icon-node"` and hides the image. A node placed across a zone/frame border gets a fill in the canvas color (`mask`).
- **Zone** = locked tinted rectangle (`customData.mydrawZone`) + title text (`mydrawZoneTitle`), grouped. Membership (also of nested zones) is `customData.mydrawZoneId`; `withGroupsAndLabels` brings a zone's contents, so `move` carries them. Deleting a zone keeps the contents (they move up to the parent zone). Zones go behind their members (`commit(..., beforeId)` inserts with `index: null`). Moving a zone rectangle (hand-drag after unlocking, arrow keys, `update_elements`) carries its contents: `web/src/zoneFollow.ts` compares each `onChange` with the previous positions and translates contents that did not move (`EVENTUALLY`, so it merges into the same undo step). Zones are locked by default.
- **Elbow arrows**: Excalidraw re-routes `elbowed` arrows itself when the user drags a bound shape, but only with `fixedPoint` bindings (ratio of the bound box, 5px outside, `gap: 0`). `restoreElements` (raw_update/set_scene of new arrows) drops such bindings, so build them with `connectorElements`. Agent moves re-route with our own `elbowRoute`. Lines can't be Excalidraw elbow arrows: an elbow line is a plain line with `customData.mydrawRouting`. Curved = round arrow with 3 points (`mydrawRouting: "curved"`).
- Excalidraw puts an arrow label at the middle point (odd count) or the middle of the middle segment (`labelPoint`); `convertToExcalidrawElements` shifts multi-point arrows, so `connectorElements` re-applies the route.
- `auto_layout` moves an existing legend to the bottom-right below the new layout (whole-drawing runs only). `layoutGraph` runs `avoidTitleStrips` on orthogonal routes: a run through a zone title is nudged past it, or jogged around it when an end point is pinned to its node.
- Legend rows: icon nodes (kind or stencil name), and shapes/arrows with `customData.mydrawKind` (`kind` in build_diagram). Legend elements carry `mydrawLegend`; `add_legend` replaces old ones.

## Export (Phase 6, part 1)
- Renderer: `web/src/exportImage.ts` (`renderExport`, `renderFrameExports`, `renderClipboard`, `listFrames/findFrame`, `exportElements(api, scope, ids, frameId)`). Formats: png, jpg, webp (`exportToCanvas` → `toBlob('image/webp')`), svg, html, pdf, pptx, drawio (part 2, below), mermaid, csv, markdown. Frame scope exports the frame + children with `exportingFrame` (Excalidraw ignores padding then). Previews are always PNG (text formats return text). `FORMAT_EXTENSION` maps mermaid → `.mmd`, markdown → `.md`.
- Pure logic in `shared/` (vitest in `tests/export.test.ts`): `sceneGraph.ts` (`extractGraph`: nodes = icon nodes + shapes with a label or user customData, zones, bound arrows; legend/deleted/decoration skipped), `mermaidWriter.ts` (`toMermaid`; labels quoted, escaped with Mermaid entity codes `#quot; #124; #37;`, which `unquote` in `shared/mermaid.ts` decodes; ids from label slugs, unique, never reserved words), `inventory.ts` (`toCsv` neutralises formula cells with a leading `'`, `toMarkdownTable`; aliases ip/ipAddress/address, hostname/host/fqdn, notes/note/description), `htmlExport.ts` (`buildHtml`, `sanitizeSvg`; CSP meta, no external requests).
- Inventory columns come from `customData` keys that don't start with `mydraw` (`build_diagram` `data` writes them).
- Main (`app/src/main.ts`): `file:export` (save dialog, any `ExportExtension`), `file:export-files` (folder picker, one file per frame, names via `batchFileStems`), `file:auto-export` (writes `<file>.png|svg` only for a path in `allowedPaths`; `siblingPath`), `clipboard:write` (Electron 45's clipboard API is promise-based: `clipboard.write([new ClipboardItem(...)])`).
- Auto-export (dialog section "Keep an image up to date", with help text naming the real file): `settings.autoExport` = `{ [absolute .excalidraw path]: "png" | "svg" }`, toggled in the export dialog; `autoExport()` in `App.tsx` runs after every successful save (autosave too) with the dialog's last-used options; failures toast but never fail the save.
- MCP `export`: `format` (or path extension), `scope` all|selection|frame|frames, `frame` (name or id), `ids`, `padding`, `scale`, `background` (false = transparent), `darkMode`, `quality`, `embedScene`. `scope: "frames"` takes a folder as `path` and returns `{files:[{frame,path}]}` (except pdf/pptx/drawio: one file). Part 2 adds `pageSize`, `actualSize`, `slideSize`. Mermaid/CSV/Markdown error if the scope has no nodes (nothing is written). `.excalidraw` export is whole-drawing only.
- Test hook `__mydrawTest.command(cmd)` runs a `MenuCommand` (smoke uses it for Copy As and reads the system clipboard via `app.evaluate`).

## Export (Phase 6, part 2: PDF, PPTX, draw.io, CLI)
- **Paged formats** (`PAGED_FORMATS`/`isPagedFormat` in `shared/agent.ts`): pdf, pptx, drawio. With scope `frames` they write ONE file with a page/slide per frame (empty frames skipped), not a folder; `renderExport` handles them via `exportPages` + `renderPaged` (`renderFrameExports` refuses them). Previews are still PNG of the first page. Results carry `pages` and (draw.io) `warnings`.
- **PDF**: renderer `exportToSvg` per page → `buildPdfHtml` (`shared/pdfLayout.ts`, pure: `planPdfPages`, named CSS `@page pN { size }` per page, so pages may differ in size; `fillSvg` scales the SVG) → bridge `printPdf(html)` → IPC `pdf:print` → `app/src/pdf.ts` `printHtmlToPdf`: temp file (data: URLs cap at 2 MB) in a hidden window with `javascript: false`, sandbox, own session partition that cancels every request except the temp file and `data:`; `printToPDF({preferCSSPageSize: true})`. Main returns bytes; files are written by the usual paths (`file:export` dialog / MCP). Options: `pageSize` fit (page = picture, 1 px = 1 CSS px, capped at 200 in) | a4 | letter (orientation per page, fitted inside 10 mm margins) and `actualSize` (a4/letter at 100%, tiled over sheets, orientation with fewer sheets). Page count check: `/Type /Page` occurrences.
- **PPTX**: `pptxgenjs` (dynamic import, own chunk) in the renderer; one PNG per slide (`exportToBlob` at `scale`), fitted with `fitOnSlide` on a custom 10 in wide layout (16:9 or 4:3), slide background = canvas color (dark canvas with darkMode), frame name as slide notes.
- **draw.io writer** `shared/drawioWriter.ts` (`toDrawio(pages, files, {background})`, pure): uncompressed `<mxfile>`, one `<diagram>` per page. Shapes → vertices (rounded/ellipse/rhombus, colors, strokeWidth, dashed, `sketch=1` + fillStyle when rough, rotation, opacity, font family names); bound text → cell label (html=1, `htmlLabel` escapes + `<br>`); text → `text;` cells; icon node → ONE `shape=image` cell (container id, image box, caption below); images → `image=data:<mime>,<base64>` (draw.io drops `;base64` because `;` separates style entries); zones → `container=1` cells (`mydrawZone=1`), members are children with parent-relative geometry, containers emitted parents first; frames → containers (`mydrawFrame=1`, label above); arrows → edges (source/target when bound to an exported cell, sourcePoint/targetPoint, interior points as waypoints, `orthogonalEdgeStyle` for elbow, `curved=1`, arrowhead map); user customData + link → `<object>` attributes (valid XML names only, `mydraw*` skipped). Freedraw/embeds skipped → `warnings`.
- **draw.io reader** `shared/drawioReader.ts` (`readDrawio`, pure, async because compressed pages are inflated with `DecompressionStream("deflate-raw")`): `<mxfile>` (plain or compressed pages) or bare `<mxGraphModel>`; `<object>/<UserObject>` attributes → `data` (placeholders `%name%` resolved); absolute coordinates through parents; `group` cells only offset; vertices with children / swimlane / `container=1` → zones (invisible unlabelled containers → groups); edge-label cells join their edge; unknown stencil shapes → rectangles and URL images → boxes, both reported. `shared/xml.ts` is the tiny parser/escaper both use (no DOMParser; works in vitest).
- `web/src/drawioImport.ts` (`drawioToScene`): reader output → zones (`makeZone`), labelled images → icon nodes (`makeIconNode`, image kept in place), shapes/text/edges through `buildElements` (bound arrows; edges to zones or missing ends become free arrows), mydraw frames restored; several pages → frames stacked vertically, ids prefixed `pN-`. Frame skeletons need `children: []` (the converter calls `children.forEach`).
- **CLI** (`mydraw export|convert`): `bin/mydraw.mjs` (package `bin`, `npm link` / `npm run link-cli`) spawns Electron (`$MYDRAW_ELECTRON` or this checkout's) with `app/dist/cli.cjs` (`app/src/cli.ts`); arguments travel in `MYDRAW_CLI_ARGS` (JSON) so Chromium never parses them; Chromium stderr noise is filtered (`MYDRAW_CLI_DEBUG=1` shows it plus renderer console). `shared/cli.ts` parses args (`parseCliArgs`, `CLI_USAGE`, `defaultOutput`, `inputKind`; unit-tested). The CLI main hides the Dock icon, uses a temp userData (no single-instance lock, never touches a running app), serves `web/dist` via `app/src/appProtocol.ts` (shared with main.ts), registers only `pdf:print` and `styles:get`, and loads `index.html#headless` in a hidden window. `web/src/main.tsx` renders `headless.tsx` for that hash: one off-screen `<Excalidraw>`, `window.__mydrawHeadless.run(job)` loads the input (`.excalidraw` via `parseDrawing`, `.drawio` via `drawioToScene` in Clean style) and runs the same `renderExport`/`renderFrameExports`/`serializeScene`; binary results come back base64 through `executeJavaScript`. `getAppState()` does not see an `updateScene` from the same tick: pass style explicitly. Exit codes: 0 ok, 1 error, 2 usage. Refuses to overwrite its input.

## Colors and styles (Phase 4)
- `shared/palettes.ts`: two palettes only: `basic` (~45 named colors; ramp-named ones equal the ramp's 500) and `ramp` (22 hues x 10 shades, generated from `HUES`). `resolveColor` is the one place color names become hex (names before hex, so "red" is never read as hex). Use `requireColor` for agent input.
- `shared/styles.ts`: `BUILTIN_THEMES` (19, categories Classic/Light/Dark/Technical/Color), `BUILTIN_PRESETS` (~37, categories Zones/Links/Status/Emphasis/Text), `normalizeStyle/Preset/Theme/Library` (validate untrusted input), `stylePatch(style, kind)`. Theme re-inks only strokes equal to some theme's ink (`inkColors(themes)`, includes user themes), so custom colors survive theme switches.
- **Persistence**: user presets/themes are global, not per drawing: `app/src/styles-store.ts` keeps `<userData>/styles.json` (IPC `styles:get/save`, bridge `getStyleLibrary/saveStyleLibrary`), `web/src/styleStore.ts` is the renderer cache (`stylesReady`, `allPresets/allThemes`, `savePreset/saveTheme/delete*`). A saved entry with a built-in's id overrides it; deleting it restores the built-in. The old localStorage key `mydraw.stylePresets` is migrated once.
- `web/src/agent/styles.ts`: `styleElements` / `applyThemeToScene` go through `applyUpdates` (text re-measure, label re-fit in a second pass), so one call = one undo step. Icon-node containers are left alone; images and frames are skipped.
- `web/src/StyleSection.tsx`: panel section (tabs Colors / Presets / Themes; collapsible groups; Manage mode with edit/delete; editors; `ColorPicker` from `IconColorSection` for any color), portaled into a host at the top of Excalidraw's panel column (MutationObserver in `App.tsx`; Excalidraw's own Stroke/Background rows are hidden). The smoke test finds it by `.md-style`: wait for something inside it (e.g. the Icon chip) rather than the section itself.
- MCP: `list_palettes`, `list_themes` (themes + presets), `apply_theme`, `apply_style_preset`, `save_style_preset`, `delete_style_preset`, `save_theme`, `delete_theme`.

## Ease of use (Phase 7)
- **Gotchas**: the disk is case-insensitive, so never name a logic file like a component in the same folder (`textSearch.ts` vs `FindReplace.tsx`, `quickConnectOps.ts` vs `QuickConnect.tsx`, `lintOps.ts` vs `LintPanel.tsx`). Excalidraw handles shortcuts only while its container has focus: after closing the palette we focus `[data-md-tab=<id>] .excalidraw`; tests focus `.md-drawing:not([style*="display: none"]) .excalidraw` (the first `.excalidraw` in the DOM may belong to a hidden tab). Excalidraw's undo does not track `customData`. Toolbars cover the top ~250px of the canvas in tests: put shapes at y >= 300. Excalidraw's `normalizeLink` leaves relative paths alone, so `link` can hold file paths.
- **Command palette**: `web/src/CommandPalette.tsx` (UI), `web/src/paletteItems.ts` (`buildPaletteItems(ctx)`: everything it can run, built each time it opens), `shared/fuzzy.ts` (`fuzzyRank`). Opened by ⇧⌘P, or ⌘K when nothing is selected (App.tsx keydown, capture). Excalidraw's own palette is never rendered (CommandPalette is not public API in 0.18.1).
- **UI actions on a drawing**: `web/src/uiActions.ts` (`commitElements` = one undoable merged `updateScene`; `applyThemeTo`, `applyPresetTo`, `selectedIds`, `linkOwners`/`setSelectionLink`). Templates from the UI go through IPC `ui:apply-template` (`window.mydraw.applyTemplate`), which runs the agent's `apply_template` (icons are resolved in main).
- **Find & replace**: `shared/findReplace.ts` (pure, literal, whole word), `web/src/textSearch.ts` (`findMatches`, `replaceAll` via `relabel`/`remeasureText`, `selectMatches`), `web/src/FindReplace.tsx` (⌥⌘F).
- **Pages**: `web/src/PagesPanel.tsx` + `web/src/pages.ts`; page order = position (`byPosition` in `shared/pageOrder.ts`, used by `listFrames`), `movePage` swaps two neighbours with `swapOffsets` and moves their contents with `applyUpdates`.
- **Drill-down links**: `shared/links.ts` (`resolveLink`, `linkProblem`, `fileLink`); `DrawingView` passes Excalidraw's `onLinkOpen` (links to elements are left to Excalidraw) to `App.onOpenLink` -> `bridge.openLink(link, baseFile)` -> main `link:open` (validates, `shell.openExternal` for http(s) unless `MYDRAW_TEST`, opens a `.excalidraw` via `open()`); `link:pick-drawing` for the palette command. Relative links resolve from the saved drawing's folder and need it saved.
- **Quick connect**: `web/src/QuickConnect.tsx` is a fixed-position DOM overlay for the active tab (`key={activeId}`). **When handles show**: on the one *selected* unit at once (selection polled every 120 ms, `selectedUnit`), or on the unit the pointer has rested on for `HOVER_DELAY_MS` (600 ms; a pending timer re-hit-tests when it fires; passing over shapes shows nothing). It listens for `pointermove`/`pointerdown` on the tab's `[data-md-tab]` root (capture, passive) and hit-tests with `quickSourceAt`. A rAF loop follows scroll and zoom while handles show. It hides them when Excalidraw is busy (`suppressed()`: non-selection tool, editing, drag, resize, rotate, dialogs, more than one selected unit) or when App passes `blocked`. A handle is drawn only where `elementsFromPoint` hits the canvas. Handles sit close (16px out when hovered; 22px, top 38px, when selected, just beyond Excalidraw's resize/rotate handles); a hovered (not selected) unit gets a dashed `.md-qc-outline` so it's clear whose handles they are. The empty inside of a shape that holds other elements does not count as hovering it (`holdsOthers`). **Source = a unit** (`QuickUnit`, `unitFor` in `web/src/quickConnectOps.ts`): a shape, an icon node, a *stencil from the Stencils panel* (a bare `image` + free caption in one group, NOT an icon node), or the whole outermost group (what a click selects); `id` = the main element (`pickPrimary`: biggest shape/image). Not units: lone free text, arrows/lines/freehand, frames, zones, legend, anything with a locked member. Modifier: `linkModifier` (⌘ on macOS, where Ctrl-click is a right-click; Ctrl elsewhere). **Actions** (on a handle): **click = copy only, no arrow** (gap `QUICK_COPY_GAP` 20, margin 10); **Option-click = connected copy** (gap 80); **⌘-click or ⌘-drag = link mode** (`web/src/LinkMode.tsx`, see "Routing around shapes" below); Shift-click / right-click = stencil search (`addConnectedStencil`). The handle icon shows the held modifier (plus / arrow / link). `attach` places the copy with `quickConnectBox` on the unit box, clones every member with `cloneForInsert` (keeps only `mydraw*` customData, drops `link`), and, when connecting, binds `pickAnchor(members, side)` to `pickAnchor(copy, opposite side)` through `buildElements` (elbow, fixed-point bindings; a stencil's caption is the anchor for the bottom side so the arrow doesn't cross the text). **Containers**: a shape, zone or frame drawn around the unit (`containersOf`: its box contains the unit's) is not an obstacle; the copy is placed inside the innermost one when there is room (`within` in `quickConnectBox`: gaps 80, 60, 44, 30, 8px inset), else outside as usual. Zones/frame grow to fit; selection is in the same update so each add is one undo step. Pure parts: `shared/quickConnect.ts` (`quickConnectBox`, `growToContain`, `pickPrimary`, `pickAnchor`, `unionBox`). Smoke finds handles as `.md-qc-handle[data-side=…]` and the search as `.md-qc-search .md-qc-input`.
- **Diagram lint**: pure rules `shared/lint.ts` (`lintScene(elements, {rules, allowedColors})`: overlap, unconnected-arrow, unlabeled-node, missing-ip (only when some node has an ip, via `inventoryField`), off-palette-color (allowed: palettes, theme inks/backgrounds, presets, `ZONE_PALETTE`, zone tints, `mydrawIconColor`, extras)). `web/src/lintOps.ts` (`lintDrawing`, `applyLintFixes` = one undo step, `revealIssue`) is shared by `LintPanel.tsx` (⌥⌘L, `toggleLint`, right of the canvas, re-lints at most every 300 ms) and MCP `lint_diagram {drawing?, fix?, rules?}` -> `{issues, summary, fixed?}`. Safe fixes only: bind a free arrow end to a node within 40px, snap a color to the nearest palette color. Overlaps, labels and IPs are never changed automatically.

## Data features (Phase 8)
- **Properties**: `shared/properties.ts` (`PROPERTY_FIELDS`, `readProperties`, `applyProperties`: canonical keys, aliases removed on write, "mydraw*" reserved). `web/src/PropertiesSection.tsx` is rendered in the same portal as `StyleSection` (one selected shape / icon node via `linkOwners`). `customData` changes are NOT in Excalidraw's undo history. MCP `get_inventory` / `set_properties` (executor).

## Routing around shapes (⌘-link, route_around)
- **Router**: `shared/avoidRoute.ts` (pure, `tests/avoidRoute.test.ts`). `routeAround({start, startSide, end, endSide?, startBox, endBox, obstacles, waypoints, clearance 16, stub 20, bendCost 40})`: A* over a sparse orthogonal grid made of the inflated obstacles' edges (+ the leg's end points), state = (node, direction), cost = length + bend penalty, no U-turns, leaves straight out of `startSide` (stub) and arrives at the stub in front of `endSide` from any direction but straight back. Facing sides: lined-up ports with nothing between = one straight segment; a short gap shrinks the stubs to half of it (otherwise the stubs overshoot each other and the route doubles back). Legs between waypoints; obstacles limited to a 400px region around each leg. Clearance falls back 16 → 8 → 2; if still blocked a plain elbow with `ok: false`. `compress` keeps reversal corners (dedupe in routing.ts would drop them). Helpers: `portPoint`, `nearestSide`, `snapRatio` (quarter points), `fixedSegmentsFor`, `crossesBox`, `alignedPorts` (facing sides that overlap across get both ports on one line, so the link is straight; with an aimed spot only when it lies in the overlap; not with bend points or curved links).
- **Durable arrows**: an around-arrow is a native elbow arrow (`aroundFields` in sceneOps: fixedPoint bindings, `elbowed`, `roundness: null`, `startIsSpecial/endIsSpecial: false`) whose middle segments (index 2..n-2) are Excalidraw `fixedSegments`: when a bound shape is dragged Excalidraw only redraws the end runs (`handleEndpointDrag`), so the route survives, the user can still drag segments, and save/load keeps it (restore doesn't re-route). Routes with < 4 points have no fixed segments (Excalidraw re-routes them freely). `customData.mydrawAvoid = true` marks them: `reroute()` (agent moves, `applyUpdates`) re-routes them with `rerouteAround` (sides/positions kept via `nearestSide` of the old endpoints); other elbow arrows get `fixedSegments: null` on re-route (stale segments would not match). `routingFields` (explicit routing style) drops `mydrawAvoid`.
- **Obstacles** (`avoidObstacles` in sceneOps): every element's drawn box except arrows/lines/freehand/frames, text inside shapes, the excluded ids (arrow, ends, unit members), things inside an end box (an icon's image/caption) and things drawn around an end (zones/boxes it sits in).
- **Link mode** (`web/src/LinkMode.tsx` + `web/src/linkOps.ts`): `LinkPlanner(api, sourceUnitId, side)` snapshots the scene and plans previews (`plan(end, waypoints, routing, unitOf)`; `end` = `{unitId, side|"auto", ratio}` or `{point}`; "auto" tries all 4 sides and keeps the cheapest). `createLink` builds the arrow via `buildElements` (current style, boundElements) and overrides geometry; one undo step; selection untouched. Window capture listeners (the overlay has `pointer-events: none`, so wheel/zoom keep working): pointerdown on a target = connect (Shift = keep going), on empty canvas = bend point, a second empty click within 450ms/8px = free end (pointer events carry no click count; the following `dblclick` is swallowed or Excalidraw would start a text), off-canvas = end link mode, right-click/Esc = cancel; pointerup after a drag from the handle onto a target = connect. Keys (swallowed so Excalidraw tools don't switch): R routing (around/elbow/straight/curved), A heads (end/both/none), D dashed (persisted in `localStorage mydraw.linkStyle`), Backspace removes the last bend, Enter ends at the pointer. Pointing within `SIDE_BAND` (22 screen px) of a target side picks that side and the nearest quarter point; over the middle the best side is picked. Body class `md-linking` = crosshair cursor. Smoke selectors: `.md-qc-linkmode`, `.md-qc-path`, `.md-qc-target`, `.md-qc-port`, `.md-qc-wp`, `.md-qc-link-keys`.
- **Elsewhere**: palette "Route arrows around shapes" (`routeArrowsAround`: selected arrows, else all; one undo step); MCP `connect {avoid: true}` and `route_around {ids?}`.

## How to drive mydraw (for Claude)
0. A whole diagram: `build_diagram` (or `mermaid_to_scene`, `apply_template`); then refine with the steps below and `auto_layout` to tidy.
1. `list_drawings` / `new_drawing` / `open_drawing`; `get_scene` for ids.
2. Shapes with labels in one `add_elements` call (give your own ids like `"web1"` so you can refer to them); arrows as `{type:"arrow", from, to, label}` in the same call or via `connect`.
3. Icons: `search_stencils "ec2"` → `place_stencil {id, right_of: "web1", label: "web-1"}`; connect to the returned `node` id. Zones: `create_zone {label, ids}`. Connectors: `routing: "elbow" | "curved"`.
4. `screenshot` to check the layout; fix with `move` / `update_elements`; `zoom_to_fit` so the user sees it.
5. `save {path}` and `export {path: ".../x.png"}`; other formats by extension (`.webp .svg .html .pdf .pptx .drawio .mmd .csv .md`), `scope: "frame"`/`"frames"` for frames (pdf/pptx/drawio: one file, a page/slide per frame), `get_scene` first to see frame names. PDF: `pageSize` fit/a4/letter, `actualSize`; PPTX: `slideSize`.
6. Without the app: `mydraw export x.excalidraw --format pdf --scope frames`, `mydraw convert x.drawio --to excalidraw`.
7. Text to diagram: `import_diagram {format: csv|yaml|mermaid, text | path}` (CSV host list or from/to list, YAML spec with `a -> b: label` edges, Mermaid). Properties: `set_properties {id, properties}`; review: `get_inventory`. Arrows: `connect {from, to, avoid: true}` routes around shapes; `route_around {ids?}` re-routes existing ones; `lint_diagram {fix: true}` applies the safe fixes.

## Conventions
- Excalidraw is pinned to `0.18.1`. Import types from `@excalidraw/excalidraw/types` and `@excalidraw/excalidraw/element/types`.
- `process.env.IS_PREACT` must stay defined as `"false"` in `vite.config.ts`.
- Fonts are copied from the package into `web/public/fonts` by `scripts/build-app.mjs` (gitignored).
- Edit menu: undo/redo/select-all use `registerAccelerator: false` so the keys reach Excalidraw.
- No browser `alert/confirm`; use the main-process dialogs (`askUnsaved`) or in-app banners/toasts.
